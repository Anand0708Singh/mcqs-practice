# IT5058 Web Technologies with .NET - MCQ Practice Portal

A modern, responsive, interactive web application built for live practice and self-assessment of the **465 Multiple-Choice Questions (MCQs)** from `IT5058 Web Technologies with .NET (Units V & VI)`.

Designed to be hosted directly on **GitHub Pages**.

---

## ✨ Features

- **465 Verified Questions**: Complete coverage of Units V & VI:
  - Unit V: Working with Razor Views, Razor Syntax, ViewBag, TempData, Layouts, Partial Views, Content-Encoding.
  - Unit VI: Model Binding, Model Validation, Creating Form Applications, Online Payment, Sending Emails, Login with Social Media.
- **Two Flexible Modes**:
  - **🎯 Practice Mode**: Instant validation after each selection with color-coded feedback and correct answer explanations.
  - **⏱️ Exam / Self-Assessment Mode**: Timed mock test with real-time question palette, flag/unflag for review, and progress tracking.
- **Dynamic Shuffling**:
  - **Question Shuffling**: Questions appear in a completely randomized sequence every session.
  - **Option (Answer) Shuffling**: Choices A, B, C, D are independently shuffled to eliminate positional memorization.
- **Filtering & Customization**:
  - Filter by specific Unit or Topic.
  - Pick question limits: Quick 20, Standard 50, Intensive 100, or All available.
- **In-Depth Results & Analytics**:
  - SVG Score ring and performance breakdown (% score, correct, incorrect, skipped, time taken).
  - Categorized review list (filter by All, Incorrect, Correct, or Flagged).
  - One-click **"Retry Incorrect Questions"** button.
- **Modern UI & Dark Mode**:
  - Clean responsive design tailored for mobile, tablet, and desktop screens.
  - Dark / Light mode toggle with persistent local preference.
  - No external backend or npm installation needed — pure static web app ready for GitHub Pages.

## 🛠️ How to Enable GitHub Pages

1. Push this repository to `https://github.com/Anand0708Singh/mcqs-practice`.
2. Go to your repository on GitHub.
3. Click on **Settings** > **Pages** (under "Code and automation" in the left sidebar).
4. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
5. Select branch **`main`** (or `master`) and folder **`/ (root)`**, then click **Save**.
6. GitHub Pages will build and publish your site in 1-2 minutes!
